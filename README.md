# Social Content Generator - Agentic AI Marketing Suite

An AI-powered multi-platform social media content generator and marketing suite powered by **Google Gemini 2.5/3.6 AI models** (`@google/genai` SDK) and real AI visual generation engines.

![Social Content Generator Banner](https://ai.google.dev/static/site-assets/images/share-ais-513315318.png)

---

## ✨ Features & Capabilities

- 🤖 **Multi-Platform Content Synthesis**: Generates posts tailored for LinkedIn, X (Twitter), Instagram, Facebook, YouTube Shorts, Threads, and Pinterest.
- 👁️ **Deep Gemini Vision Inspector**: Performs RGB pixel-level analysis on uploaded product photos to extract true colors, surface texture, material quality, and design parameters.
- 🏢 **Business Profile & Brand Hook Management**: Custom business profile integration to anchor all generated content around your unique value proposition and brand tone.
- 📝 **Interactive Inline Post Editor**: Edit post text directly on any platform card before publishing or exporting.
- ⚡ **A/B Hook Selector**: Interactive scroll-stopping headline switcher with 1-click application.
- 🏷️ **Smart Tiered Hashtags Matrix**: High-volume, niche-targeted, and community hashtags categorized for optimal reach.
- 📊 **Virality Index & Quality Review Audit**: Self-checking QA score and platform algorithm optimization insights.
- 🎨 **Prompt-Matched AI Visual Studio**: Real-time image generation per platform with custom aspect ratios, resolution options, and style presets.
- 📥 **1-Click Export Suite**: Export full campaign reports as structured **Markdown (.MD)** files or copy all channel captions with one click.

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+)

### Installation & Local Run
```bash
# 1. Install dependencies
npm install

# 2. Configure Environment Variables
# Add your Gemini API key in .env or environment
GEMINI_API_KEY=your_gemini_api_key_here

# 3. Start Development Server (Express + Vite)
npm run dev
```

### Build & Production Deployment
```bash
# Typecheck & Lint
npm run lint

# Build Vite frontend and bundled Express server
npm run build

# Start Production Server
npm run start
```
